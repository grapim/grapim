Install it once with `npm install -g grapim` and run `grapim <command>`. Install it globally rather than through `npx`: the agent hooks call grapim on every edit, and npx runs packages from a cache npm may clear. It needs Node 22.13 or newer; undo and the provenance commands also need git.

This page is generated from the help text of the Grapim version this site runs. For the version you have installed, run `grapim help`.
